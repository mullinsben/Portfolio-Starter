# Portfolio Starter

Read `GIVE-THIS-TO-YOUR-AI.md` before editing anything in this repo. It is the operating manual: how the pages are wired, the recipe for every common change (new essay, lab page, case study, image swap, rename), the rules that keep the site from breaking, and the checks to run before saying a change is done.

The short version: never write a page from scratch, duplicate the nearest one; every new page comes with a homepage card, a sitemap line and an `llms.txt` line (gated case studies get the card only); render at desktop and phone before you call it finished.
